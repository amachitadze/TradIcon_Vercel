# Tradicon [Ka, Es] — ესპანური ენის მრავალფუნქციური პლატფორმა

**Tradicon** არის წარმოებისთვის მზა (Production-Ready), მაღალეფექტური Progressive Web App (PWA), შექმნილი ქართულ და ესპანურენოვანი მომხმარებლებისთვის. აპლიკაცია აერთიანებს ესპანური ზმნების მძლავრ კონიუგატორს, ორენოვან ლექსიკონს, მთარგმნელს ტექსტისა და გამოსახულების ამოცნობით, გრამატიკული დახვეწის მოდულსა და ინტელექტუალურ სასაუბრო ჩატს — Google Gemini API-ს უახლესი შესაძლებლობების გამოყენებით.

---

## 🚀 ტექნოლოგიური სტეკი

- **Build Tool & Bundler:** [Vite 6](https://vitejs.dev/)
- **პროგრამირების ენა:** Strict [TypeScript](https://www.typescriptlang.org/) (ES2022)
- **ხელოვნური ინტელექტი:** [@google/genai SDK](https://www.npmjs.com/package/@google/genai) (Google Gemini 2.5 Flash)
- **მომხმარებლის ინტერფეისი:** სუფთა CSS3, თანამედროვე Glassmorphism დიზაინი, ადაპტური განლაგება (Mobile-First)
- **PWA მხარდაჭერა:** Service Worker (`sw.js`) ქეშირების სტრატეგიით და Web App Manifest (`manifest.json`)
- **დეპლოიმენტი:** ოპტიმიზირებულია [Vercel](https://vercel.com/)-ზე მყისიერი და უწყვეტი CI/CD გაშვებისთვის

---

## 🌐 Vercel-ზე დეპლოიმენტის სრული გზამკვლევი

პროექტი სრულად არის კონფიგურირებული Vercel-ისთვის (`vercel.json`, ოპტიმიზირებული ბილდ-სკრიპტები, SPA გადამისამართებები და უსაფრთხოების ჰედერები).

### ნაბიჯი 1: კოდის ატვირთვა GitHub-ზე
დარწმუნდით, რომ პროექტის უახლესი კოდი ატვირთულია თქვენს GitHub რეპოზიტორიაში.

### ნაბიჯი 2: პროექტის იმპორტი Vercel-ში
1. შედით [Vercel Dashboard](https://vercel.com/dashboard)-ზე.
2. დააჭირეთ **"Add New..."** -> **"Project"**.
3. აირჩიეთ თქვენი GitHub რეპოზიტორია და დააჭირეთ **"Import"**.

### ნაბიჯი 3: ბილდ-პარამეტრების გადამოწმება
Vercel ავტომატურად ამოიცნობს პროექტს, თუმცა დარწმუნდით შემდეგ პარამეტრებში:
- **Framework Preset:** `Vite`
- **Root Directory:** `./`
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
- **Install Command:** `npm install`

### ნაბიჯი 4: გარემოს ცვლადების (Environment Variables) დამატება ⚠️ (კრიტიკულია!)
იმისათვის, რომ Gemini-ის ხელოვნურმა ინტელექტმა იმუშაოს შეუფერხებლად:
1. პროექტის იმპორტის გვერდზე გახსენით განყოფილება **"Environment Variables"** (ან დეპლოის შემდეგ გადადით: *Settings > Environment Variables*).
2. შეიყვანეთ შემდეგი მონაცემი:
   - **Key (სახელი):** `GEMINI_API_KEY`
   - **Value (მნიშვნელობა):** თქვენი Google AI Studio-ს API გასაღები (მაგალითად: `AIzaSy...`)
3. მონიშნეთ სამივე გარემო: **Production**, **Preview**, **Development**.
4. დააჭირეთ **"Add"**.

*(შენიშვნა: სისტემა ასევე მხარს უჭერს ცვლადს სახელწოდებით `API_KEY`)*

### ნაბიჯი 5: დეპლოიმენტი
დააჭირეთ **"Deploy"** ღილაკს. ბილდი წარმატებით დასრულდება და თქვენ მიიღებთ მზა, მაღალი წარმადობის ბმულს (მაგ. `tradicon.vercel.app`).

## 🔑 როგორ მივიღოთ Google Gemini API გასაღები

1. გადადით [Google AI Studio](https://aistudio.google.com/)-ზე.
2. გაიარეთ ავტორიზაცია თქვენი Google ანგარიშით.
3. დააჭირეთ ლურჯ ღილაკს **"Get API key"**.
4. აირჩიეთ არსებული Google Cloud პროექტი ან შექმენით ახალი ერთი დაწკაპუნებით (**"Create API key in new project"**).
5. დააკოპირეთ გენერირებული გასაღები და ჩასვით Vercel-ის ან ლოკალურ `.env.local` ფაილში.

## 💻 ლოკალური გაშვება და დეველოპმენტი

თუ გსურთ პროექტის ლოკალურ კომპიუტერზე გაშვება:

1. **დამოკიდებულებების ინსტალაცია:**
   ```bash
   npm install
   ```

2. **გარემოს ცვლადების კონფიგურაცია:**
   შექმენით `.env.local` ფაილი `.env.example`-ის საფუძველზე:
   ```bash
   cp .env.example .env.local
   ```
   გახსენით `.env.local` და ჩაწერეთ თქვენი გასაღები:
   ```env
   GEMINI_API_KEY=თქვენი_გასაღები_აქ
   ```

3. **დეველოპერული სერვერის გაშვება:**
   ```bash
   npm run dev
   ```
   აპლიკაცია გაიხსნება მისამართზე: `http://localhost:3000`

4. **საწარმოო ბილდის ტესტირება:**
   ```bash
   npm run build
   npm run preview
   ```

## 🛡️ უსაფრთხოება და PWA ქეშირება

- **API გასაღების დაცვა:** გასაღები არასდროს იწერება კოდში და იმართება მხოლოდ გარემოს ცვლადების მეშვეობით (`.env.local` / Vercel Environment Variables).
- **Service Worker (`sw.js`):** განახლებულია `v11` ვერსიამდე. არარსებული რესურსების ამოღებით გარანტირებულია ოფლაინ ინსტალაციის სტაბილურობა.
- **Cache-Control:** `vercel.json` უზრუნველყოფს, რომ `sw.js` არასდროს დაკეშირდეს ბრაუზერის მიერ (`no-cache`), რათა განახლებები მომენტალურად აისახოს მომხმარებლებზე.
